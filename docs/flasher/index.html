🐷PoC-KBD Web Flasher

Flash your board over USB, straight from the browser — no esptool, no drivers. All targets are ESP32-S3.

This browser can't flash over USB. Use Chrome or Edge on desktop (Windows / Linux / macOS). Web Serial isn't available on Firefox, Safari, or phones. You need to open this page over https.

Before you click Install

  • Connect the board with a USB-C data cable and pick its serial port in the popup.
  • These boards run native USB as an HID keyboard, so they don't auto-reset into download mode. Put the board in download mode first, then Connect:
    • T-Embed: hold BOOT, tap RESET, release BOOT.
    • T-Dongle: hold its button while plugging the USB-A in.
    • Headless (no button): tie GPIO0 → GND while plugging in.
  • Updating a board that already runs PoC-KBD? Leave Erase device unticked — your saved WiFi + payloads live in separate partitions and are preserved. Only tick Erase device for a clean first install.
  • After flashing, tap RESET (or unplug/replug without BOOT/GPIO0 held) to start the new firmware.

What is this?

A USB-HID → BLE-HID pairing-bootstrap keyboard: the board types just enough to pair its own BLE keyboard, then persists as a wireless keyboard. Control it from the phone portal (Web Bluetooth).
