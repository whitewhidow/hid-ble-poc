Type & timing

Print <text>Type text, no Enter.
PrintLine <text>Type text, then Enter.
STRING <text>Same as Print (alias). {MAC} expands to the board's BLE MAC.
ENTERPress Enter.
Delay <ms>Wait this many milliseconds.

Keys

Press <key>Hold a key down. Stack several, then Release — e.g. Press KEY_LEFT_CTRL / Press KEY_LEFT_ALT / Press KEY_DELETE / Release.
PressRelease <key>Tap a key once (press + release).
ReleaseRelease everything currently held.
CTRLALT <key>Tap Ctrl+Alt+<key> (alias).
GUI <key> / GUI SPACETap Super/Win+<key> (alias).
