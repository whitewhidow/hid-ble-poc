Media / consumer keys

Consumer <name|code>Send any HID Consumer-page key (usage page 0x0C). Covers the whole practical page — media (play pause playpause stop next prev ff rewind record eject randomplay repeat), audio (mute volup voldown bass treble bassboost loudness balance), display (brightup brightdown), channel/menu (channelup channeldown menu menuup…), the full app-launch range (calc email files browser mediaplayer wordproc spreadsheet database contacts calendar taskmgr documents desktop controlpanel lock logoff screensaver clock wallet … AL 0x181–0x1C7), and app-control (new open close save print undo redo cut copy paste selectall find search goto webhome webback webfwd webrefresh bookmarks zoomin zoomout scrollup scrolldown bold italics underline reply send … AC 0x201–0x2A4). Anything else: pass a raw usage, e.g. Consumer 0x1A7. Also the buttons + the raw-code box in the Keyboard tab.
